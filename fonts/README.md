# Fontes

As fontes são **auto-hospedadas** para eliminar requisições ao Google Fonts,
reduzir latência e preservar a privacidade do visitante.

| Arquivo | Família | Uso |
| --- | --- | --- |
| `inter-latin.woff2` | Inter (variável 400–700) | Texto corrido e interface |
| `fraunces-latin.woff2` | Fraunces (variável 400–700) | Títulos |
| `fraunces-italic-latin.woff2` | Fraunces Itálico (400) | Destaques editoriais |

Subconjunto **latin**, suficiente para o português (ã, ç, é, ê, õ etc.).
